# Mukundprabha Bakery Website (मुकुंदप्रभा बेकरी)

A premium, high-performance static website and interactive product catalog built for **Mukundprabha Bakery**, an established local bakery, sweet, and farsan store based in Kasaba Bawada, Kolhapur, Maharashtra. 

This website was designed and built from scratch as a freelance project to establish the client's online presence, showcase their 170+ product catalog, and drive local customer inquiries.

---

## 🚀 Live Demo & Deployment
- **Built for**: Mukundprabha Bakery
- **Coordinates**: [16.730961456722206, 74.2425345227243](https://maps.google.com/?q=16.730961456722206,74.2425345227243)
- **Tech Stack**: Vanilla HTML5, Custom CSS3, Native JavaScript (ES6+)

---

## ✨ Key Features

- **Devanagari UI & Localization**: Fully designed using Devanagari/Marathi typographic hierarchy (`Tiro Devanagari Marathi`) alongside modern sans-serif bodies to connect directly with the local customer base.
- **Instant Product Search & Filter**: A custom JavaScript-powered search filter that indexes Devanagari text matching search queries (like "चटणी", "लाडू", "चिवडा", "पेप्सी") instantly across 8 categories without server lag.
- **8 Product Categories Catalog**: Structured grid catalog containing Sweets, Namkeen & Farsan, Wafers & Snacks, Biscuits, Dairy, Masalas & Chutneys, Premium Cupcakes, and Soft Drinks.
- **Lightbox Gallery**: Fully interactive photo gallery featuring real storefront neon branding and product assets with smooth transitional sliders.
- **Responsive Layouts**: Coded with mobile-first CSS grids and media queries to scale gracefully across mobile phones, tablets, and high-DPI desktop viewports.
- **Interactive Call-to-Action Grid**: Linked Whatsapp API, call capabilities, and the Google Maps Directions API targeting the exact coordinates of the shop.
- **Fail-safe Image Handling**: Embedded fallback CSS gradients that seamlessly replace any missing product assets, preserving visual appeal at all times.

## 🛠️ Tech Stack & Architecture

- **Frontend markup**: HTML5 (semantic, structured, SEO-optimized)
- **Styling & Theme**: CSS3 (custom properties, glassmorphic card overlays, glow shadows, parallax scrolling, cubic-bezier scroll transitions)
- **Client Scripts**: Vanilla JS (event throttling, error boundary intercepts for images, class-driven active states)
